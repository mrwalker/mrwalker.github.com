I've recently been asked to write several blog posts around our composable agent architecture and how we've been using Snowflake Cortex to build our latest generation of AI applications at Simon. This morning, with just a single cup of coffee in my left hand, I used my right to index past content (blog posts, LinkedIn articles, and outlines I've been working on) into a Claude project. Then I hooked up the Atlassian Confluence MCP server and started iterating through with Claude Sonnet 4 in extended thinking mode.

The experience is surreal – exactly like collaborating with a very smart colleague who sometimes leaps to some odd conclusions, but is very receptive to feedback and can read entire articles or API docs in seconds.

I found that Claude got hung up on the successive process I directed it through primarily in making successive updates to the Confluence page we were working on. Sometimes it would take a long time to generate a change set and then fail the update, but each time it would drop back, attempt to understand what had failed, and then try again. But simply with some patience, the end result was an exceptionally high-fidelity 3,000+ word technical draft that saved me many hours of banging my head against linguistic boilerplate, and even threw in some almost-there code examples to boot!

I'd definitely recommend taking the "Cyborg" approach to using an AI assistant to write your next blog post, even if it's just to marvel at how far the tech has come in this area.
